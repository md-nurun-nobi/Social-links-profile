# Social Links Profile

A responsive **Social Links Profile** built with **HTML, Tailwind CSS, and Vite** based on a Frontend Mentor challenge.

##  Live Demo

[View Live Project](https://social-links-profile-one-lilac.vercel.app/)

##  About The Project

This project is a simple social links profile card that presents a user's profile information and social media links in a clean, modern, and responsive layout.

The main goal of this project was to practice building a responsive UI with Tailwind CSS while following a provided design specification.

##  Features

- Responsive design for mobile and desktop screens
- Centered profile card layout
- Circular profile image
- Profile name and location
- Short profile description
- Social media link buttons
- Hover effects on social links
- Keyboard focus styles for better accessibility
- Custom colors using Tailwind CSS
- Inter font from Google Fonts

##  Built With

- HTML5
- Tailwind CSS v4
- Vite
- Google Fonts — Inter
- Vercel

##  Design Specifications

### Colors

- Green: `hsl(75, 94%, 57%)`
- White: `hsl(0, 0%, 100%)`
- Grey 700: `hsl(0, 0%, 20%)`
- Grey 800: `hsl(0, 0%, 12%)`
- Grey 900: `hsl(0, 0%, 8%)`

### Typography

- Font family: **Inter**
- Regular: `400`
- Semi Bold: `600`
- Bold: `700`
- Body text: `14px`

### Responsive Design

The design was tested with different viewport sizes, including:

- Mobile: `375px`
- Desktop: `1440px`
- Responsive range: approximately `320px` and above

##  Accessibility

Some accessibility practices used in this project include:

- Semantic HTML elements
- Descriptive `alt` text for the profile image
- Keyboard focus styles for interactive links
- Sufficient text and background contrast
- Proper heading structure

##  Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Go to the project directory

```bash
cd social-links-profile
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL shown in the terminal.
